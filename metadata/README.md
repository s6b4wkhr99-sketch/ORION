# Ceragem CIOS Metadata Repository

Central metadata definitions for CIOS. Runtime reference data is seeded from:

- `backend/app/reference/registry.py` — Reference Data Library (Volume 22)
- `backend/app/mapping/data_dictionary.py` — Field dictionary (Volume 09)
- `backend/app/rules/library.py` — Business rules (Volume 10)
- `backend/app/knowledge/registry.py` — Documentation index (Volume 21)

Update metadata when merging features per Volume 25 §13 Documentation Synchronization.
