ORION v1.5.1 — 다른 Mac 설치 오류 해결 (psycopg2 / Xcode / Python)
====================================================================
Updated: 2026-08-02
대상: Option A (USB source + backups) 설치 중 setup-local 실패

증상 (에러 로그)
----------------
- xcode-select: note: No developer tools were found
- pg_config executable not found
- psycopg2-binary 빌드 실패
- pip version 21.2.4 (구버전)
- ERROR: No matching distribution found for psycopg2-binary==2.9.10

원인
----
1. Xcode 앱 설치 ≠ Command Line Tools 경로(xcode-select) 자동 설정
2. make setup-local 을 Install Runbook §2 없이 실행 → macOS 기본 python3 로 venv 생성
3. PostgreSQL(Homebrew) 미설치 → pg_config 없음
4. 구 pip / 잘못된 Python → psycopg2-binary wheel 실패 → 소스 빌드 시도 → 실패

해결 요약 (한 줄)
-----------------
Xcode CLI 경로 설정 → brew install python@3.12 postgresql@16 → venv 삭제 후 python3.12 -m venv → make setup-local

====================================================================
STEP 1 — Xcode Command Line Tools 경로
====================================================================

xcode-select -p

# 경로가 없거나 에러면:
sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
xcode-select -p
# 기대: /Applications/Xcode.app/Contents/Developer

# CLI만 별도 설치가 필요하면:
xcode-select --install

====================================================================
STEP 2 — Homebrew + Python 3.12 + PostgreSQL + Node
====================================================================

# Homebrew 없으면: https://brew.sh

brew install python@3.12 postgresql@16 node

--- Apple Silicon (M1/M2/M3) ---
echo 'export PATH="/opt/homebrew/opt/postgresql@16/bin:$PATH"' >> ~/.zprofile
source ~/.zprofile

--- Intel Mac ---
echo 'export PATH="/usr/local/opt/postgresql@16/bin:$PATH"' >> ~/.zprofile
source ~/.zprofile

--- 확인 ---
which python3.12
which pg_config
pg_config --version
python3.12 --version

====================================================================
STEP 3 — 잘못된 venv 삭제 → Python 3.12로 재생성
====================================================================

cd ~/ORION
rm -rf backend/.venv

# which python3.12 결과에 맞게 경로 선택:

# Apple Silicon:
/opt/homebrew/bin/python3.12 -m venv backend/.venv

# Intel:
# /usr/local/bin/python3.12 -m venv backend/.venv

backend/.venv/bin/python --version
# → Python 3.12.x (3.9/3.14 아님!)

backend/.venv/bin/python -m pip install --upgrade pip

====================================================================
STEP 4 — Option A 설치 계속 (DB 포함)
====================================================================

cd ~/ORION

make setup-local
make setup-data
make postgres-up
make restore
make migrate
bash scripts/dev.sh start --with-worker

====================================================================
STEP 5 — 확인
====================================================================

pg_isready -h 127.0.0.1 -p 5432
curl -s http://127.0.0.1:8000/api/v1/health

브라우저: http://127.0.0.1:3002/login
로그인:   user@company.com / Ceragem2026!Adm

흔한 추가 오류
====================================================================

|------|------|
