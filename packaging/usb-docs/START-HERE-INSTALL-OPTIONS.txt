ORION / Ceragem CIOS — LeFrame_Dev USB
======================================
Installation: TWO OPTIONS (choose one)
Updated: 2026-07-28 · Guide v1.5.0

Replace ORION-vX.Y.Z with: ORION-v1.5.0  (only package on LeFrame_Dev USB)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
OPTION 1 — Full Migration (DB included)
  Best for: demo, QA, same snapshot as source Mac, full 2.6M search
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  cp -R "/Volumes/LeFrame_Dev/ORION-v1.5.0/source" ~/ORION
  mkdir -p ~/ORION/backend/backups
  cp -R "/Volumes/LeFrame_Dev/ORION-v1.5.0/backups/"* ~/ORION/backend/backups/
  cd ~/ORION
  make setup-local && make setup-data && make postgres-up
  # Fresh DB: drop/create cios DB first (see docs/Other_Mac_Operations_Guide.md §2.3)
  make restore          # uses database.sql.gz — BEFORE migrate
  make migrate
  bash scripts/dev.sh start --with-worker
  # First start: wait 1-3 min for .next build; if /login 500 → dev.sh restart

  Verify: OTHER-MAC-VERIFY.txt

  Login: http://127.0.0.1:3002/login
  user@company.com / Ceragem2026!Adm

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
OPTION 2 — System First (upload data on local Mac)
  Best for: campaign ops Mac, latest schema, lighter disk, controlled search
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  cp -R "/Volumes/LeFrame_Dev/ORION-v1.5.0/source" ~/ORION
  # Do NOT copy backups/
  cd ~/ORION
  make setup-local && make setup-data && make postgres-up
  make migrate          # NO make restore
  bash scripts/dev.sh start --with-worker
  # First start: wait for .next; if /login 500 → dev.sh restart

  Then upload data in the browser:
    Prospect CSV  → http://127.0.0.1:3002/import
    Buyer CSV     → http://127.0.0.1:3002/buyer-import

  Login: same as Option 1
