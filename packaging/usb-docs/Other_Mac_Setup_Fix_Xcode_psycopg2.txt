ORION v1.5.1 — 다른 Mac 설치 오류 복구 (Xcode / psycopg2)
========================================================
Updated: 2026-08-02
대상: Option A (USB source + backups) 설치 중 setup-local 실패

증상 (에러 로그)
----------------
• xcode-select: note: No developer tools were found
• pg_config executable not found
• psycopg2-binary 빌드 실패 / No matching distribution found
• pip version 21.2.4 (구버전 — macOS 기본 python3 로 venv 생성됨)

원인
----
1. Xcode 앱 설치 ≠ Command Line Tools 경로(xcode-select) 자동 설정
2. make setup-local 을 §2 venv 단계 없이 실행 → 시스템 python3 + 구 pip
3. PostgreSQL(Homebrew) 미설치 → pg_config 없음 → psycopg2 소스 빌드 실패

해결 요약
---------
Xcode CLI 경로 설정
  → brew install python@3.12 postgresql@16 node
  → rm -rf backend/.venv
  → python3.12 -m venv backend/.venv
  → make setup-local

--- PostgreSQL PATH (Apple Silicon M1/M2/M3) ---

echo 'export PATH="/opt/homebrew/opt/postgresql@16/bin:$PATH"' >> ~/.zprofile
source ~/.zprofile

--- PostgreSQL PATH (Intel Mac) ---

echo 'export PATH="/usr/local/opt/postgresql@16/bin:$PATH"' >> ~/.zprofile
source ~/.zprofile
